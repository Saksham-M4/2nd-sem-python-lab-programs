🧪 QUIZ EXPLANATION — ONE BY ONE
🔹 QUESTION 1
try:
    print("A")
    x = int("10")
    print("B")
except ValueError:
    print("C")
print("D")
Step-by-step execution
print("A") → prints A
int("10") → valid conversion ✅ (no error)
print("B") → prints B
No error happened → except is skipped
print("D") runs
✅ Output
A
B
D
🧠 Key idea
except runs ONLY IF an error happens inside try.
🔹 QUESTION 2
try:
    print(10 / 0)
except ValueError:
    print("Value error")
except ZeroDivisionError:
    print("Zero error")
print("Done")
Step-by-step
10 / 0 → ❌ causes ZeroDivisionError
Python checks except ValueError → ❌ no match
Python checks except ZeroDivisionError → ✅ match
Prints "Zero error"
Program continues → prints "Done"
✅ Output
Zero error
Done
🧠 Key idea
Python checks except blocks top to bottom.
🔹 QUESTION 3
try:
    x = int("abc")
except Exception:
    print("Handled")
    raise
print("End")
Step-by-step
int("abc") → ❌ raises ValueError
except Exception catches it
Prints "Handled"
raise → re-throws the SAME error
Program crashes ❌
print("End") ❌ does NOT run
✅ Output
Handled
ValueError traceback
🧠 Key idea
raise inside except rethrows the error.
🔹 QUESTION 4
try:
    try:
        print(10 + "5")
    except TypeError:
        print("Inner handled")
except Exception:
    print("Outer handled")
print("Finish")
Step-by-step
10 + "5" → ❌ TypeError
Inner except TypeError catches it
Prints "Inner handled"
Error is handled → outer except is skipped
print("Finish") runs
✅ Output
Inner handled
Finish
🧠 Key idea
If inner except handles the error, outer one never sees it.
🔹 QUESTION 5 (IMPORTANT)
def test():
    try:
        return 10
    except:
        return 20
    finally:
        return 30

print(test())
Step-by-step
try runs → return 10
BEFORE returning → finally executes
finally has return 30
return 30 overrides everything
✅ Output
30
🧠 Key idea
finally always runs and overrides return.
🔹 QUESTION 6
try:
    raise ValueError("X")
except ValueError:
    print("Caught")
Step-by-step
raise ValueError("X") → creates error
except ValueError catches it
Prints "Caught"
✅ Output
Caught
🧠 IMPORTANT CONCEPT
You do NOT need try to use raise.
try is only needed to catch, not to raise.
